# 函数是一等公民

先说说一等公民 —— 能够像普通值一样参与程序运算，简单来说，即可以赋值，传参数，返回等之类的

首先函数本身就是值 ——

```go
func Add(a, b int) int {
	return a + b
}

f := Add
fmt.Println(f(1, 2))
```

此处的类型推导可以等价视作 ——

```go
var f func(int, int) int = Add
```

它是一个“值”而不是函数指针之类的实现

那么作为参数传递的话 ——

```go
type Operation func(int, int) int

func Calculate(a, b int, op Operation) int {
    return op(a, b)
}

func main() {
    add := func(a, b int) int {
        return a + b
    }

    multiply := func(a, b int) int {
        return a * b
    }

    fmt.Println(Calculate(3, 4, add))      // 7
    fmt.Println(Calculate(3, 4, multiply)) // 12
}
```

我们利用 `type` 让 `func(int, int) int` 这样的一个函数签名也作为一种“数据类型"，然后在 `Calculate` 中传这样的一个操作进行调用，不赖，在 c++ 中可能就需要定义一个 callable 来进行实现（或者进行一个 oop 💦

那么值得注意的，在闭包捕获变量的时候，虽然可能复制了函数值，但是其捕获的变量依旧是一份引用，而不会重新深拷贝一份出来，比如 ——

```go
x := 10

f := func() int {
    return x
}

g := f

x = 20

fmt.Println(f()) // 20
fmt.Println(g()) // 20
```

那么假设如果需要每一次赋值的时候都复制一份副本的话，可以在自己的域内借助捕获重新复制一份出来，比如 ——

```go
x := 10

f := func() int {
	return x
}

g := f

var h func() int

{
	snapshot := x

	h = func() int {
		return snapshot
	}
}

x = 20

fmt.Println(f()) // 20
fmt.Println(g()) // 20
fmt.Println(h()) // 10
```

（不过其实这样写有一点刻意就是），或者其实更常见的，利用一个即时函数来捕获环境中的变量并且做一次拷贝存在当前的闭包中，比如 ——

```go
x := 10

f := func(snapshot int) func() int {
    return func() int {
        return snapshot
    }
}(x)

x = 20

fmt.Println(f()) // 10
```

以及神奇的 —— 上文说到其实函数签名可以作为一种数据类型的声明，那么其也可以作为方法的 Receiver ——

```go
type Predicate func(int) bool

func (p Predicate) Not(x int) bool {
    return !p(x)
}

func IsEven(x int) bool {
    return x % 2 == 0
}

func main() {
    var p Predicate = IsEven

    fmt.Println(p(4))     // true
    fmt.Println(p.Not(4)) // false
}
```

此处我们先利用 `type` 定义出谓词这个类型，它拥有一个方法 `Not`；接着实现了一个是否为偶数的函数 `IsEven`，它的类型为 `func(int) bool` —— 说过函数也可以视作”值“，所以声明了一个类型为 `Predicate` 的变量 `p`，展开即 `func(int) bool` —— 正好是 `IsEven` 的类型，接着把 `IsEven` 赋值给 `p`
